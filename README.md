# VCR Jam Timer

Practice jam timer for Volcanic City Rollers.

**https://volcaniccityrollers.github.io/timer/**

## Features

- WFTDA-correct whistle signals (synthesised Fox 40-style)
- "Five seconds" voice announcement with visual countdown
- 1 short blast to start jam
- 4 short blasts x3 to end jam
- Auto-end at 2:00
- Wake lock keeps screen on during jams
- Fully self-contained single HTML file — no dependencies

## Whistle Signals (WFTDA)

| Signal | Pattern |
|--------|---------|
| Jam start | 1 short blast |
| Jam end / call off | 4 short blasts (repeated 3x) |

## Usage

Open on your phone, connect to a bluetooth speaker if needed, and tap Start Jam.
